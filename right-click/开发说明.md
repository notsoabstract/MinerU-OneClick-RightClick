# 右键工具开发说明

日常使用直接打开 `dist` 中的安装器与设置入口，不需要编译。已发布的 MSIX 和 CER 配套提供；CER 只含公开证书，不含签名私钥或 API。

## 源码结构

- `src`：独立 Windows 程序、识别流程、加密设置和进度窗口。
- `shell`：原生右键扩展、Windows 接口声明及本地测试源码。
- `packaging`：包清单、打包脚本、安装登记和精确证书清理脚本。
- `dist`：可直接安装的完整发布文件。
- `tests`：不依赖个人 API 的本地逻辑与界面检查。

## 编译

`build.ps1` 使用 Windows 的 .NET Framework C# 编译器生成 `dist/MinerURightClick.exe`。

`shell/Build-Shell.ps1` 使用 TinyCC；脚本期望编译器在 `tools/tcc/tcc/tcc.exe`。此 Git 包不复制外部编译器，需另行准备。

`packaging/Build-Package.ps1` 使用 Windows SDK 中的 MakeAppx 和 SignTool；脚本期望它们在 `tools/sdk-buildtools/bin/10.0.26100.0/x64`。该打包脚本使用 PowerShell 7 运行；安装脚本兼容 Windows PowerShell 5.1。

发布包的私钥和签名密码均不在仓库中，因此不能使用作者私钥重新签名。若生成自己的新签名证书，必须同步更新 `Machine-Certificate.ps1` 的固定证书指纹及 SHA256，并同步源码、发布脚本、公钥证书、包校验信息与清单。证书校验不会自动接受另一枚证书。

API 默认从用户配置读取；不要把自己的 Token 写入源码。构建依赖、签名材料、测试输出和个人设置已经在根 `.gitignore` 中排除。
